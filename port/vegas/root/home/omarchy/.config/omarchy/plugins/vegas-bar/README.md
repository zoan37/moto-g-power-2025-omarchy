User-owned clone of the pinned Omarchy ARM bar; packaged source is unchanged.
Generated by scripts/prepare-vegas-phone-bar.py. Geometry overrides are
phoneSafeTop, phoneSideInset and phoneBarHeight in shell.json bar config;
phoneLockLayout (default true) disables the drag-to-move, drag-to-reorder and
double-tap transparency gestures, which ordinary touch swipes would trigger.
Base file hashes are pinned in that script. Hardware fit check pending.
