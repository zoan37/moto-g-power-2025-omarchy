# Sensors via MediaTek's sensor hub (2026-10-11)

## Access

The sensor drivers run on the SCP coprocessor (whose image LK loads; audio-prepare already loads `scp.ko`). Two
vendor_dlkm modules give Linux the client side: `hf_manager.ko` (no deps) and `sensorhub.ko` (deps: hf_manager, scp,
mtk-afe-external, tinysys IPI, mbox). They create **`/dev/hf_manager`** (misc, root-only). Source:
`third_party/kernel/kernel-mtk/drivers/misc/mediatek/sensor/2.0/core/` (`hf_manager.c`, `hf_sensor_io.h`).

Protocol (one client per open):
- `ioctl(HF_MANAGER_REQUEST_SENSOR_INFO = _IOWR('a', 6, 68-byte ioctl_packet))` with `sensor_type` in byte 0 returns
  `{status, gain, name[16], vendor[16]}`
- `write(struct hf_manager_cmd)` (52 bytes): `{u8 type, u8 action (1 enable, 0 disable), u8 length,
  pad, data[48] = struct hf_manager_batch {s64 delay_ns, s64 latency_ns}}`
- `poll` + `read` gives `struct hf_manager_event` records (76 bytes): `{s64 timestamp, u8 type, u8 accuracy,
  u8 action (0 = data), pad, s32 word[16]}`

Types follow **Android's numbering**. Present on this phone:

| type | sensor | chip |
|---|---|---|
| 1 | accelerometer (word × 1/1000 m/s²) | ST LSM6DSO |
| 2 | magnetometer | MEMSIC MMC56xx |
| 4 | gyroscope | LSM6DSO |
| 5 | **ambient light** (word[0] = lux) | Sensortek STK3A5x |
| 6 | pressure | Bosch BMP580 |
| 8 | **proximity** | STK3A5x |
| 3, 9–11, 14–20, 35 | orientation, gravity, linear accel, rotation vectors, uncalibrated, step, significant motion | MTK fusion |
| 22 | tilt | MTK |
| 27 | "Disprot" (display rotation) | Motorola |
| 131 | second ambient light | Sensortek STK6A2x |

Live check: light 42 lux, accelerometer (1.72, −0.49, 9.69) m/s² (lying flat), gyro streaming.

## Adaptive brightness

`vegas-sensors.service` (`sensors-prepare`: loads the modules, plus the SCP chain if audio is off; opt out with
`/var/lib/vegas/no-sensors`) and `vegas-autobrightness.service` (`/usr/local/sbin/vegas-autobrightness`, root):

- light sensor at 5 Hz while the screen is on (disabled while `vegas-screen-off` exists)
- smoothing: brightens with τ 1.5 s, dims with τ 8 s
- log-lux curve, roughly Android's default: 0 lux 2% … 30 lux 16% … 600 lux 55% … 10000 lux 100%; the floor is 1%
- ramps at most 4% of the range per 100 ms
- a manual backlight change (the shade's slider) is learned as a multiplicative offset at the current light level
  and kept in `/var/lib/vegas/autobrightness.json`. **On the first run the offset is learned from the existing
  brightness** (otherwise the stock curve dropped the user's 888 to 403 at 42 lux).
- off switch: `~/.config/vegas/auto-brightness` = `off`; the shade's brightness icon toggles it (shows an "A" when
  on)

## Auto-rotate

- Hyprland rotates at runtime with
  `hyprctl eval 'hl.monitor({ output = "DSI-1", mode = …, position = "0x0", scale = …, transform = N })'`.
  The bars, nav bar and wvkbd re-lay out in landscape, with no display-driver errors.
- **Hyprland does not rotate touch with the output** (`input:touchdevice:transform` is 0, "not set"). Tested with
  injected taps: in transform 1 a tap at the raw-scaled portrait position of Home hit it. With
  `hl.config({ input = { touchdevice = { transform = 1 } } })` the physically correct spot (portrait right edge
  middle, 995,1195) hit Home. So the UI's bottom is along the phone's right side in transform 1.
- `vegas-autorotate` (session daemon, autostart.lua; `/dev/hf_manager` is group input, set by sensors-prepare)
  reads the accelerometer at 5 Hz while the screen is on and `~/.config/vegas/auto-rotate` is `on` (shade tile
  "Auto-rotate"; default off = portrait):
  - y > 6.5 m/s² → portrait (0)
  - x < −6.5 → transform 1 (turned clockwise)
  - x > +6.5 → transform 3
  - |z| > 8.5 (flat) → keep the current rotation; the orientation must be stable for 0.6 s; no upside-down portrait
- **Verified by the user (2026-10-11):** with the tile on, turning the phone sideways rotates the UI the right way
  up, and touch follows. Type 27 ("Disprot", Motorola's own rotation decision) reported −1 while flat; it could replace
  the accelerometer logic once its values are known.
- The shade dropped its Keyboard tile (the nav bar has a keyboard button) for Auto-rotate: 8 tiles.
